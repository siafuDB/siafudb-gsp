# siafudb-sync

The SiafuDB Graph Sync Protocol (GSP): mutation model, conflict resolution,
and transport adapters. Extracted from `siafuDB/siafudb` with history.

**Status: pre-release.** Mutations are not yet signed or content-addressed;
see the design notes in the main repo (`docs/spike/03-mutation-format.md`)
before depending on the wire format.
